# NOTE4C 操作手册（实测版）

## 当前固件：TRMNL v1.8.19（拉图模式，2026-11-26 刷入）

| 操作 | 说明 |
|------|------|
| 短按正面圆形键（EXT0） | 唤醒 + **刷新当前面板数据** |
| 短按侧面下方键（EXT1）单击 | 唤醒 + **正循环**（用量→天气→日历） |
| 侧面下方键双击（5 秒内两次） | **反循环**（后退一屏） |
| 定时唤醒（15 分钟） | 自动回到默认面板「日历」 |
| 短按左侧内凹 RESET 针孔 | 芯片硬复位（电池供电也能重启，回形针戳） |
| 默认行为 | 每 15 分钟自动醒来 → 拉图 → 内容变了才刷屏 → 深睡 |

- 服务器：`http://<MAC_IP>:4567`（Mac 上的 BYOS，launchd 常驻）
- 渲染：`CodexPlugin` → 4 色索引 PNG（400×300，调色板黑/白/黄/红）→ 固件 `png_draw_4clr` 全刷
- 内容不变时 filename token 稳定，设备自动跳过刷屏（保护屏寿命）
- 深睡时 USB 串口不枚举（正常现象）；配网需要擦 NVS（0xE000, 0x5000）后重启进 portal
- 图片格式铁律：**必须走 PNG 通道**（BMP 通道在四色屏按 1-bit + PARTIAL 处理，静默失败）

## 按键

| 物理键 | 短按（<0.5s） | 长按（~2s） |
|--------|--------------|------------|
| 正面圆键（BOOT） | 唤醒 / 确认 / 看详情 | 进入传图模式（AP 热点）；在传图模式下再长按 = 退出 |
| 左侧键 | 移动选择 / 上一张 | **打开快捷切换（相册 / 设置）** |
| 右侧键 | 移动选择 / 下一张 | **打开快捷切换（相册 / 设置）** |

- 快捷切换列表只有两项：相册、设置。左右键移动 → BOOT 确认。
- 相册空时按 BOOT 显示「无法加载照片」，正常。

## 关键时机

1. **深睡时只有 BOOT 能唤醒**（左右键完全无响应，不是坏了）
2. **唤醒后屏幕刷新约 20 秒，期间输入锁死**（事件被丢弃）——等屏幕完全静止再操作
3. 空闲后设备自动休眠（同步休眠计时器）；**「局域网服务/HTTP 服务」运行期间不休眠**

## 局域网服务

- 设置页 →「局域网服务」（或 HTTP 服务）打开 → 显示设备 IP（当前 <DEVICE_IP>）
- 开启后 Mac 可用 HTTP 接口推图：
  - `GET /status` — 服务状态
  - `POST /upload?format=bwry2bpp` — 推 400×300 四色原始数据（30000 字节）
  - `GET /photos` / `POST /photo/meta` / `DELETE /photo` — 相册管理
  - `POST /photo/show` — 立即显示指定图（**v6.5.9-20260705 无此接口，404**，刷新版固件后可用）
- 推图命令：
  ```bash
  cd "/Users/hunter.zong/Work/Test Pj/NOTE4C"
  python3 render_codex.py --device <设备IP> --push --meta "Codex用量监控"
  ```
  推上去的图在相册里，回相册页即可看到/翻页。

## 已知坑

- `/api/push_memory`：相册空状态页的提示文案有误导，**当前固件无此接口**
- 设置页可开关 Wi-Fi（BOOT 切换），关了 Wi-Fi 局域网服务也随之失效
- Wi-Fi SSID：<WIFI_SSID>，设备静态经验 IP <DEVICE_IP>（DHCP，可能变化，以设置页显示为准）
